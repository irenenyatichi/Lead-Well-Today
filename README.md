# Lead Well Today website source

This ZIP contains the updated website source, including the navigation contrast fix,
working program accordions, and the redesigned Voices of Transformation gallery.

## Add your images
Create a folder named `public/images` and put your image files inside it. Then reference
them in the site using paths such as `/images/your-photo.jpg` in CSS or HTML.

The hero background currently uses an Unsplash image URL. The testimonial portraits are
currently initials placeholders, ready to be replaced with your real photos.

## Run locally
1. Install Node.js.
2. Extract this ZIP.
3. Open a terminal in the extracted folder and run `npm install`.
4. Run `npm run dev` to preview the site.
5. Run `npm run build` to create the production site in `dist`.

The site uses Vite.
